## Задание 1. Методы

### 1.6 Большая буква

### 1.8 Делитель
Функция `isDivisor` проверяет, делит ли одно число другое нацело.  

### 1.10 Многократный вызов

## Задание 2. Условия
### 2.2 Безопасное деление
Функция `safeDiv` выполняет деление, возвращая 0 при попытке деления на ноль.  

### 2.4 Строка сравнения
Функция `makeDecision` возвращает строку с числами и знаком сравнения между ними.  

### 2.6 Тройная сумма
Функция `sum3` проверяет, равна ли сумма двух любых чисел третьему.  

### 2.8 Возраст
Функция `age` склоняет слово "год" в зависимости от числа (год, года, лет).  

### 2.10 Вывод дней недели
Функция `printDays` выводит название дня и всех последующих до воскресенья с использованием `switch`.  

## Задание 3. Циклы
### 3.2 Числа наоборот
Функция `reverseListNums` возвращает строку с числами от `x` до 0.  

### 3.4 Степень числа
Функция `power` возводит число `x` в степень `y` через цикл.  

### 3.6 Одинаковость
Функция `equalNum` проверяет, все ли цифры в числе одинаковы.  

### 3.8 Левый треугольник
Функция `leftTriangle` выводит левосторонний треугольник из символов `*`.

Функция `findLast` возвращает индекс последнего вхождения числа в массив.
